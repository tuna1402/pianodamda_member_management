# 실제 통계와 디자인 적용 v0.10

2026-10-04 KST. 기존 v0.9의 인증/권한/일정/모의 문자/보관 정책을 보존한 화면·집계 확장이다. 실제 업체 발송이나 공개 배포 완료를 의미하지 않는다.

## 통계 계약

`GET /api/admin/statistics?anchor=YYYY-MM-DD&period=7d|28d`는 일반 원장 세션만 조회할 수 있다. 기준일 기본값은 KST 오늘, 범위는 기준일 포함 7일 또는 28일이다. 7일은 일별, 28일은 시작일부터 연속 7일씩 4구간이다. KST 날짜 문자열을 비교하며 한 SQLite 읽기 트랜잭션으로 카드·차트·숫자 표의 원본을 반환한다.

- 기간 확정 일정: `op_calendar`의 현재 확정 상담/체험/수업. 임시/취소/휴무/정기 요일 메모 제외.
- 완료 수업: `records`의 수업일과 완료 상태. 원장 집계는 공개 여부와 무관하며 예정/취소/무효 제외.
- 오늘 카드: 선택 기준일과 별도인 실제 KST 오늘의 확정 일정. 날짜를 라벨에 표시한다.
- 알림: 선택 기간과 별도인 전체 현재 상태. 대기/보류/처리/접수/성공/실패/확인 중/발송 전 취소 모두 표시한다. 알 수 없는 새 상태는 기타·확인 필요에 합산한다.
- 확인할 알림: 보류/실패/확인 중과 미등록 상태. 이미 안내한 일정 변경은 별도 처리할 일로 표시한다.

개인 이름·연락처·본문·내부 메모는 통계 응답에 포함하지 않는다. 현재 보관 중인 원본을 조회하므로 수정·파기 뒤 과거 값도 달라진다. 과거 시점 스냅샷·매출·진도율·완료율/문자 성공률은 추가하지 않았다. 실제 업체가 연결되지 않아 `mode=mock`이며 모의 접수의 성공을 실제 전달 실적으로 해석하지 않는다.

## 화면과 에셋

회원은 이번 과제→현재곡/목표→수강정보→공개 수업 이력 순서로 배치했다. 이미지 배너와 음악 선은 장식이며 alt를 비웠다. 사진은 실제 학원 사진이 아닌 생성 이미지다. 기존 시안의 원본과 프롬프트를 `public/assets`에 보존했다. 운영 대시보드는 실제 통계 카드·SVG 차트·숫자 표·전체 알림 막대와 업무 버튼을 함께 제공한다.

사진/SVG/JS/CSS/HTML은 명시한 파일만 제공하고 없는 URL은 404다. 설정/DB/프롬프트 기록은 웹에 제공하지 않는다. MIME/nosniff/CSP를 적용하며 에셋 때문에 외부 스크립트나 inline 스타일을 허용하지 않는다. 느린 이전 기간 조회와 로그아웃 뒤 조회는 화면을 덮어쓰지 않는다.

## 실행과 검증

Node 24 이상, `npm start`. 개발 새 DB는 합성 계정을 만들고 운영 모드는 기존 HTTPS/원장 설정/운영 전환/복원 검수를 요구한다. 영구 DB·삭제 목록·상시 알림 실행을 확보하기 전에는 무료 체험 서버를 실제 운영으로 쓰지 않는다.

`npm test`에 기존 검사 + `statistics-test.mjs` + 통계 UI 회귀가 포함된다. `npm run test:live`는 실제 시계의 모의 알림 검사를 별도 실행한다. 테스트는 메모리 또는 새 합성 DB이며 실제 문자 API를 호출하지 않는다. 기존 UI 테스트의 작은 DOM 모형을 실제 브라우저·스크린리더 검수로 환산하지 않는다.
